# CLI reference

> Generated by `tools/gen_cli_reference.py` from the code. Do not edit by hand.

Boolean options take `0/1`, `true/false` or `yes/no`. List options take comma-separated values (`1,2,2`); integer lists also accept ranges (`0-63`).
